# AI Web School LP

要件定義書PDF `ToC_WebSchool_LP_Requirements_2026-08-31.pdf` をもとに作成した、地方在住者向け AI × Web制作オンラインスクールのLPです。

## ファイル

- `index.html`: LP本体
- `styles.css`: デザイン、レスポンシブ、追従CTA
- `script.js`: スムーススクロール、CTAクリック計測

## 公開前に差し替える項目

- LINE URL: `https://line.me/R/ti/p/@your-line-id`
- GA4 ID: `G-XXXXXXXXXX`
- スクール正式名称
- 運営者・アドバイザーのプロフィール、実績、写真
- 税込・税別、開催時間、定員、受講後フォローの期間・回数
- 特商法表記、プライバシーポリシー、キャンセル・返金規定
